Student Support System Architecture — version 1.0

Open student-support-architecture.drawio in diagrams.net / draw.io:
File > Open From > Device. The eight numbered tabs are editable pages.

Open architecture-overview.html in a browser for the PNG preview gallery.
Keep architecture-previews alongside that HTML file.

Read student-support-secure-design.html for detailed requirements, decisions,
permissions, threats, verification plan and unresolved institutional policies.

Views: 01 context; 02 containers/trust boundaries; 03 components; 04 deployment;
05 business data; 06 security/operational data; 07 workflow/referral; 08 sequence.

The source .drawio uses native XML shapes/connectors, not embedded screenshots.
PNG previews are generated from the same model; draw.io may wrap labels differently.
XML structure and graph references were checked; the file has not been opened
in a native draw.io installation during this session. Proposed target architecture,
not a deployment or a statement of university approval. No application code included.
